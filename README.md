[![License: MIT](https://img.shields.io/badge/License-MIT-brightgreen.svg)](LICENSE)

An end-to-end machine learning system for detecting whether a given source code snippet was written by a **Human developer** or generated by an **AI system**. Built by fine-tuning Microsoft's **CodeBERT** (`microsoft/codebert-base`) sequence classification model.

---

## 📌 Features

- **Transformer-based Detection**: Employs fine-tuned CodeBERT model embeddings to identify subtle syntactic and contextual patterns distinguishing AI-generated code from human writing.
- **Multi-Language Support**: Supports Python (`.py`), C++ (`.cpp`, `.c`, `.h`, `.hpp`), Java (`.java`), JavaScript (`.js`), TypeScript (`.ts`), and general code text files (`.txt`).
- **Complete Pipeline**: Includes dataset preprocessing, training with HuggingFace `Trainer`, logging, metric tracking, and a production CLI inference script.
- **Git LFS Enabled**: Saved model weights (`model.safetensors`) are tracked using Git Large File Storage (Git LFS) for seamless repository cloning and deployment.

## 🚀 Getting Started

### 1. Prerequisites & Installation

Clone the repository with **Git LFS** enabled so that pre-trained model weights are downloaded properly:

```bash
# Install Git LFS (if not already installed)
git lfs install

# Clone the repository
git clone https://github.com/YOGESHS347/AI-Code-Origin-Detection-using-CodeBERT.git
cd AI-Code-Origin-Detection-using-CodeBERT
```

Create a virtual environment and install the required dependencies:

```bash
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate

pip install -r requirements.txt
```

## 🎯 Usage

### Running Inference

To test a source code file against the trained model:

```bash
python inference.py <path_to_code_file>
```

#### Example Commands:

```bash
# Test a C++ file
python inference.py files/a.cpp

# Test a Python script
python inference.py path/to/your_script.py
```

---

### Training the Model

To re-train or fine-tune CodeBERT on your dataset:

```bash
python train.py
```

#### Default Training Hyperparameters:
- **Base Model**: `microsoft/codebert-base`
- **Epochs**: `3`
- **Batch Size**: `16`
- **Learning Rate**: `2e-05`
- **Max Sequence Length**: `512`
- **Validation Split**: `15%`
- **Random Seed**: `42`

---

## ⚙️ Model Architecture & Details

- **Backbone Model**: [`microsoft/codebert-base`](https://huggingface.co/microsoft/codebert-base) (bimodal pre-trained model for natural language and programming language).
- **Classification Head**: Sequence Classification layer mapping the `[CLS]` token representation to 2 target classes:
  - `0`: **Human Code**
  - `1`: **AI Code**
